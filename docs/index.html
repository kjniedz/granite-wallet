Granite Wallet is an open-source browser extension for Ethereum, Polygon, BNB Chain, Avalanche, Arbitrum, Optimism, Base and Solana. There is no server and no account. Every signature and transaction is shown to you before it happens.

Build and install Read the source

Version 1.0. The code has not yet had an independent security audit; read it, build it yourself, and use amounts you are comfortable with until it has.

Self-custody

The phrase is generated on your device, encrypted with AES-256-GCM under your password, and never sent anywhere. Private keys are derived at signing time and discarded.

Standard derivation

BIP-39 and BIP-44 for EVM chains, SLIP-0010 for Solana. The same words restore the same accounts in MetaMask, Phantom and hardware wallets.

dApp ready

Injects an EIP-1193 provider, announces itself through EIP-6963, and handles connect, personal_sign, EIP-712 typed data, transactions and chain switching with your approval each time.

No tracking

No analytics, no telemetry, no remote fonts. The only network traffic is to the RPC endpoints and CoinGecko for prices, and you can point the RPCs at your own node.

Install

Until the Chrome Web Store listing is live, build from source. You need Node 20 or newer.

git clone https://github.com/kjniedz/granite-wallet
cd granite-wallet
npm install
npm run build
  1. Open chrome://extensions in Chrome, Brave, Edge or Arc.
  2. Turn on Developer mode.
  3. Click "Load unpacked" and choose packages/extension/dist.
